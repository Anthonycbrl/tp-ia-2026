# TimeTravel Agency

Immersive AI-powered time travel webapp.

## Stack

- Next.js 14
- TailwindCSS
- Framer Motion
- OpenRouter API
- Vercel

## Features

- Cinematic landing page
- Interactive destination cards
- AI chatbot
- Personalized recommendation quiz
- Responsive UI

## AI Tools Used

- Claude Sonnet
- Groq API

## Deployment

Hosted on Vercel.
